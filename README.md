# Asystent

- `server/` – serwer na laptopa (Whisper + lokalny LLM + Piper). Instrukcja: `server/README.md`.
- `android/` – apka na Androida (okno na serwer, z dostępem do mikrofonu).

## APK
Każdy push do `android/` buduje APK w GitHub Actions.
Pobierz: zakładka **Releases** → najnowszy `Asystent APK` → `Asystent.apk`.
Przy pierwszym uruchomieniu wpisz adres laptopa z Tailscale (`https://…ts.net`).
